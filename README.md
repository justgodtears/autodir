# autodir

A small CLI tool that scans your Python project and generates a file with ready-to-use path variables — no more `../../../data/file.csv` guesswork, no matter how deep your script lives in the project tree.

## The problem

```python
# Where even is this file relative to me right now?
df = pd.read_csv("../../data/raw/ad.csv")
```

Move the script one folder deeper, and every relative path breaks.

## The solution

```python
from autodir_paths import AD_CSV

df = pd.read_csv(AD_CSV)  # always resolves correctly, from anywhere in the project
```

`autodir` scans your project once, finds every file and folder, and writes them all as `pathlib.Path` variables into a single generated file — `autodir_paths.py` — sitting in your project root. Import it from anywhere, at any nesting level, and the paths just work.

## Installation

Not published on PyPI yet — install directly from source:

```bash
git clone https://github.com/justgodtears/autodir.git
cd autodir
pip install -e .
```

## Usage

**1. Initialize** (run once per project, from the project root):

```bash
autodir init
```

This creates a `.autodirignore` file where you can list extra files/folders to exclude from scanning.

**2. Generate the paths file:**

```bash
autodir generate
```

This creates (or refreshes) `autodir_paths.py` in your project root.

**3. Use it anywhere in your project:**

```python
from autodir_paths import DATA_DIR, CONFIG_YAML

print(DATA_DIR)      # /home/you/your-project/data
print(CONFIG_YAML)   # /home/you/your-project/config.yaml
```

Re-run `autodir generate` whenever your project structure changes.

## How it works

- **Project root detection** — walks up from the current directory looking for `.git`, `pyproject.toml`, `setup.py`, or `requirements.txt`.
- **Scanning** — walks the whole project tree, skipping common noise: `.venv`, `__pycache__`, `.git`, `node_modules`, `.idea`, `*.egg-info`, plus anything you add to `.autodirignore`.
- **Naming** — file and folder names are converted to `SCREAMING_SNAKE_CASE` Python identifiers. Non-alphanumeric characters become underscores, and names can't start with a digit.
- **Collision handling** — if two files share a name (e.g. `data/ad.csv` and `archive/ad.csv`), the first one found keeps the plain name, later ones get a numeric suffix (`AD_CSV`, `AD_CSV_2`, ...). Each entry gets a `# source: ...` comment showing exactly where it came from.
- **Portable paths** — the generated file computes `ROOT` dynamically via `Path(__file__).parent`, then builds every other path as `ROOT / "folder" / "file.ext"`. This means the generated file is safe to commit to git — it resolves correctly on any machine, regardless of where the project is cloned.

## Example output

```python
# This file is auto-generated by autodir. Do not edit manually.
from pathlib import Path

ROOT = Path(__file__).parent

DATA_DIR = ROOT / "data"  # source: data
AD_CSV = ROOT / "data" / "ad.csv"  # source: data/ad.csv
AD_CSV_2 = ROOT / "archive" / "ad.csv"  # source: archive/ad.csv
CONFIG_YAML = ROOT / "config.yaml"  # source: config.yaml
```

## Ignoring extra files/folders

Add one pattern per line to `.autodirignore` (created by `autodir init`):

```
# .autodirignore
secrets
temp_output
```
